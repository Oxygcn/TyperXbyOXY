# Проверять чат назначения — настройка Студии

Установка поверх последних исправлений TyperX. Архив меняет форму Студии,
память интерфейса, проверку протокола и Python-адаптер. Зависимости, lockfiles,
ключи, сессия Telegram и Rust-манифест не меняются.

1. F9, закрыть TyperX, Ctrl+C в терминале desktop:dev.
2. Распаковать архив в существующий корень проекта с заменой файлов.
3. Выполнить .\scripts\build-engine.ps1; дождаться успешной сборки.
4. Выполнить npm run desktop:dev.
5. Студия → снять «Проверять чат назначения» → заново подтвердить Enter →
   Подготовить запуск → перейти в целевое поле → F8.

Проверка включена по умолчанию. Выбор сохраняется в памяти на время работы
интерфейса, но не на диск. Во время подготовки/печати переключатель заблокирован;
для изменения нажмите F9. После подключения новый движок показывает chat-binding-3.

Когда выключено: заголовок не читается и не сравнивается, проверка имени чата
не запускается даже в AI-режиме. Захватываются окно и PID на момент F8;
переход в другое окно останавливает ввод. Если UIA предоставляет идентификатор
поля, он также проверяется. Если UIA его не предоставляет, гарантируется только
привязка к окну. F9, отпускание клавиш, защита собственного окна TyperX остаются.
Это не режим «печатать вслед за фокусом»: цель не меняется автоматически.

AI по-прежнему слушает выбранного в TyperX собеседника и использует его историю.
Отключается только проверка назначения печати, а не выбор источника сообщений.
Возможна печать чужого контекста не тому получателю — самостоятельно проверьте
поле. Смена чата в том же окне может остаться незамеченной. Enter может отправить
сообщение. Сначала проверьте на пустом локальном документе.

Включённый режим сохраняет прежние строгие проверки; эта настройка не является
новым парсером всех вариантов заголовков Telegram. Никаких сетевых отправок
через Telethon, автоматических запусков или сброса сессии не добавлено.

Проверки: Python unit-тесты с подставными Windows API, compileall, синтаксическая
сборка TSX. Реальная Windows/Interception/Tauri сборка здесь не выполнялась.
