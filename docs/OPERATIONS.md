# Эксплуатация и диагностика

## 1. Безопасный запуск

1. Убедитесь, что F9 доступна и модификаторы Shift/Ctrl/Alt/Win не зажаты.
2. Проверьте настройки провайдера и Telegram.
3. Выберите личный чат или участника группы.
4. Проверьте текст и последствия Enter.
5. Выполните подготовку.
6. Перейдите в пустое целевое поле.
7. Нажмите F8.
8. При любом сомнении нажмите F9 и вручную проверьте черновик.

Не используйте production-чат для первого smoke test после обновления.

## 2. Жизненный цикл

Rust запускает один sidecar на Windows-профиль. Второй sidecar блокируется lock-файлом. При закрытии окна host отправляет `shutdown`, ожидает graceful exit и затем выполняет принудительное завершение. Автоматического reconnect нет: пользователь должен осознанно подключить движок повторно.

## 3. Диагностический порядок

Перед созданием issue зафиксируйте:

- commit desktop-репозитория;
- версию Windows и архитектуру;
- версии Node/Python/Rust;
- этап: connect, login, prepare, F8, typing или shutdown;
- безопасный код `[TG:...]` или `[INPUT_...]`;
- прошёл ли `build-engine.ps1` после последнего изменения bridge;
- минимальный воспроизводимый сценарий без секретов и текста чата.

Никогда не прикладывайте `telegram.session`, `ai-secrets.bin`, API hash/key, 2FA-пароль, код входа или полный stderr.

## 4. Типовые неисправности

### `ImportError` или «Соединение с Python закрыто»

Обычно исходники adapter новее собранного PyInstaller exe либо sidecar аварийно завершился до handshake.

```powershell
Get-Process typerx-engine -ErrorAction SilentlyContinue | Stop-Process -Force
git pull origin main
./scripts/build-engine.ps1
npm run desktop:dev
```

Проверьте, что build сообщил target path в `src-tauri/binaries/` и что его timestamp обновился.

### Sidecar отсутствует

Выполните bootstrap и build engine. Не переименовывайте target-triple файл вручную.

### Несовместимый snapshot

Host и sidecar должны собираться из одного commit. Пересоберите Python engine, затем Tauri. При реальном изменении контракта обновите все уровни из `PROTOCOL.md`.

### `TG_API_ID`, `TG_API_HASH`, `TG_PHONE`

Исправьте сохранённые значения. Телефон должен быть международным `+кодстраныномер`; API hash — 32 hex-символа. Не публикуйте значения.

### `INPUT_WINDOW`, `INPUT_PROCESS`, `INPUT_FIELD`, `INPUT_TITLE*`

Фокус, процесс, документ/чат или UIA-поле изменились. Приложение остановилось fail-closed. Не отключайте проверку для обхода непонятной ошибки; сначала воспроизведите в пустом локальном документе.

### F8 не запускает

Проверьте prepared state, исправность hotkeys, наличие Interception driver, пустое поле и отсутствие второго sidecar. Перезапуск не должен заменять понимание причины.

### F9 или stop во время ввода

После остановки проверьте поле и состояние клавиш. F9 предотвращает дальнейший ввод, но не отзывает Enter, уже принятый приложением назначения.

## 5. Восстановление

Безопасное восстановление — остановить sidecar, сохранить диагностический код, пересобрать из известного commit и повторить smoke test. Не удаляйте session или secret files автоматически. Logout выполняйте через приложение, если требуется отзыв Telegram-сессии.

## 6. Обновление

Перед обновлением:

1. F9 и закрытие приложения;
2. резервная копия только несекретных пользовательских настроек;
3. `git pull`;
4. просмотр lock/backend изменений;
5. bootstrap при изменении dependency graph;
6. обязательная пересборка sidecar;
7. полный test gate;
8. локальный smoke test.

Downgrade host отдельно от sidecar не поддерживается.
