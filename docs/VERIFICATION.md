# Проверка поставки

Дата: 7 сентября 2026. Это отчёт о выполненных проверках, не сертификат production-ready.

## Выполнено в доступной Linux-среде

- 12/12 unit-тестов Python protocol: allowlist, отсутствие JS start, согласие для AI, подтверждение Enter, лимиты кадра/кода/пароля, типы ID, handshake, нечисловые значения, отсутствие секретов в ошибках, честные минутные счётчики, отказ не-Windows.
- 10/10 offline-проверок Ajv: формы config/snapshot, диапазон WPM, отсутствие coercion, запрет секретов в public config, запрет произвольного URL аватара, версия/стадии протокола, отсутствие eval в сгенерированных валидаторах.
- Python compileall для bridge/scripts/tests.
- esbuild syntax/bundle parsing TypeScript/TSX и тестов. Это НЕ strict typecheck.
- Валидаторы скомпилированы Ajv из имеющейся в среде версии 8.20.0. В package.json закреплена 8.17.1; штатный build регенерирует их после npm ci.
- Визуально осмотрены обзор, студия, Telegram и мобильная компоновка 390 px. Нет горизонтального переполнения или перекрытия элементов на этих снимках.

## Ограничения визуальной проверки

Для осмотра использован отдельный offline-стенд на тех же App.tsx и CSS, с временными заменами недоступных библиотек. Он не включён в production src. Проверялись компоновка и пустые/отключённые состояния, а НЕ рабочие Radix focus trap, Motion, Zustand, Recharts, формы или IPC. Снимки не доказывают работоспособность desktop. Реального Telegram-аватара в тестах нет: аккаунт пользователя не подключался.

## Обязательный Windows smoke test

1. Выполнить bootstrap, проверить настоящие lockfiles, затем npm ci/build/test и cargo test --locked. Не публиковать без этого.
2. Проверить запуск с отсутствующим sidecar, сломанным handshake и повреждённым ai.json. Никакой печати до осознанного prepare/F8.
3. Запустить второй экземпляр: тот же профиль не должен получить второй engine.
4. Подготовить короткий ручной текст и нажать F8 в пустом тестовом документе. Убедиться, что Enter действительно ожидаем пользователем.
5. Во время ввода сменить окно и нажать F9: новых клавиш быть не должно; проверить отпускание модификаторов.
6. Остановить во время LLM запроса и сразу после prepare. Проверить отсутствие отложенного запуска и автоматического повтора.
7. Убить Python, закрыть UI, аварийно завершить Tauri. Не должно оставаться рабочего процесса, ввода или автоматического reconnect/start.
8. Войти в согласованный тестовый Telegram-аккаунт с code + 2FA. Фото должно совпасть с get_me, отсутствующее фото — нейтральная иконка.
9. Проверить chats/select для людей, групп, ботов, self и одинаковых имён. Небезопасная цель должна быть отклонена.
10. На тестовом чате проверить согласие с фактическим base URL, пустое поле, уникальный заголовок, F8, новое входящее сообщение и F9 во время generation/output.
11. Провести logout: профиль/аватар/цель очищены. Ключи не возвращаются в IPC, пароль и история не появляются в логах, localStorage, sessionStorage или файлах проекта.
12. Проверить все страницы при 1000×700 и 1440×940, масштабировании Windows 125–200%, клавиатурной навигации и reduced motion.

Выпуск намеренно заблокирован `scripts/check-locks.mjs`, пока lockfiles не существуют. CI не устанавливает драйвер и не отправляет сообщения.
