# Monkeytype в TyperX

TyperX открывает `https://monkeytype.com/` в отдельном окне WebView2, принадлежащем приложению. Авторизация и cookies сохраняются в профиле WebView2 TyperX, отдельно от обычного браузера.

## Использование

1. Откройте раздел **Monkeytype** и нажмите **Открыть Monkeytype**.
2. Войдите в аккаунт и выберите режим теста.
3. Кликните по области слов.
4. Нажмите **F6** для автоматического набора.
5. Нажмите **F9** для остановки. Переключение на другое окно также останавливает набор.

F8 остаётся горячей клавишей Telegram-движка.

## Как работает набор

Скрипт в окне Monkeytype читает только следующую ожидаемую букву активного слова из `#words`. Каждый символ отдельно передаётся Rust-команде `monkeytype_key`, которая создаёт настоящий Unicode key-down/key-up через Windows `SendInput`. Синтетические DOM `KeyboardEvent` не используются.

Перед каждым символом Rust проверяет:

- команда вызвана из окна с label `monkeytype`;
- текущий адрес — HTTPS на `monkeytype.com`;
- передан ровно один печатный Unicode-символ;
- HWND Monkeytype является foreground-окном.

Команда не принимает Enter, Tab, переносы строк или строки из нескольких символов. При потере фокуса следующий символ отклоняется, а JavaScript-цикл завершается.

## Разрешения

Удалённая страница получает отдельную capability только для `https://monkeytype.com/*` и только для команды `monkeytype_key`. Команды backend, shell, filesystem, HTTP и opener ей недоступны. Окно `main` по-прежнему единственное, которое может создать или показать окно Monkeytype.

## Ограничения

- Реализация зависит от структуры DOM Monkeytype (`#words .word.active` и элементы `letter`). При изменении сайта селекторы нужно обновить.
- Windows может отклонить `SendInput` из-за UIPI, если целевое окно работает с другим уровнем привилегий.
- Автонабор предназначен только для окна Monkeytype и не продолжает работу после Alt+Tab.
