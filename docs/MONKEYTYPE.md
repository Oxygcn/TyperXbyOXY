# Monkeytype в TyperX

Отдельное WebView-окно открывает https://monkeytype.com/. Логин остаётся в профиле WebView2 приложения.

## Использование

1. Раздел **Monkeytype** → **Открыть Monkeytype**.
2. Войдите в аккаунт на сайте, если нужно.
3. Запустите тест, кликните по словам.
4. **F6** — автонабор оставшихся букв в DOM.
5. **F9** — остановка скрипта набора.

F8 не используется: это горячая клавиша движка Telegram.

## Ограничения

Набор идёт через синтетические `KeyboardEvent` в странице. Monkeytype может игнорировать события с `isTrusted === false`. Реальный клавиатурный ввод в HWND окна — отдельная доработка, без `Enter` из операции `prepare`.

IPC со страницы monkeytype.com не выдаётся. Команда `open_monkeytype` доступна только окну `main`.
