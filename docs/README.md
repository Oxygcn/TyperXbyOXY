Эта директория содержит нормативную техническую документацию проекта. Код является источником истины при расхождении с текстом; обнаруженное расхождение следует исправлять в том же pull request, который меняет поведение.

## Нормативные термины

- **WebView** — React-интерфейс внутри Tauri.
- **Host** — Rust-процесс Tauri, владеющий жизненным циклом sidecar.
- **Sidecar / движок** — `typerx-engine*.exe`, собранный PyInstaller.
- **Adapter** — пакет `bridge/typerx_desktop`, адаптирующий upstream backend к desktop-протоколу.
- **Backend** — закреплённый внешний исходный код из `backend.lock.json`.
- **Подготовка** — операция `prepare`; она не запускает ввод.
- **Запуск** — локальное событие F8 после успешной подготовки.
- **Остановка** — F9 или операция `stop`; она не отменяет уже отправленный текст.

## Политика актуальности

Изменения следующих областей требуют обновления документации:

- IPC-команды или поля snapshot → `PROTOCOL.md`;
- разрешения, CSP, секреты, окна или сетевые потоки → `SECURITY.md`;
- зависимости, lock-файлы или build scripts → `DEVELOPMENT.md`;
- таймауты, lifecycle или диагностика → `OPERATIONS.md`;
- тесты, CI или release gates → `TESTING.md`.

Документы описывают состояние ветки `main` и не являются обещанием функциональности, отсутствующей в коде.
