# TyperX: точная диагностика остановок focus-diagnostics-2

Устанавливать поверх TyperX-input-auth-fix. Эта правка устраняет потерю причины
ошибки в обработчике, но не объявляет неизвестную причину остановки исправленной.

Ошибка INPUT_FOCUS раньше объединяла разные проверки. Теперь разделяются:
INPUT_WINDOW — активное окно; INPUT_PROCESS — PID; INPUT_TITLE — заголовок;
INPUT_TITLE_STRICT — заголовок при недоступной безопасной нормализации;
INPUT_FIELD — идентификатор UIA поля; INPUT_UIA_UNAVAILABLE — недоступность UIA;
INPUT_KEYBOARD_WINDOW — проверка окна непосредственно драйвером перед клавишей.
Для печати также указываются этап preflight/characters/enter и номер фрагмента.
Не записываются заголовки окон, имена собеседников, текст или секреты.

Не отключены проверки, F9, остановка и отпускание клавиш. Не добавлено
автовозобновление. Настройки Telegram и локальная сессия не изменяются.

Установка:
1. F9, закрыть приложение, Ctrl+C в терминале desktop:dev.
2. Распаковать архив в существующий корень проекта с заменой файлов.
3. Пересобрать: .\scripts\build-engine.ps1
4. Только после успешной сборки: npm run desktop:dev

После подключения до запуска detail содержит focus-diagnostics-2.
Сначала тест в пустом локальном документе, не в реальном чате.
При остановке прислать целиком новую строку ошибки, указать приложение
(Блокнот/Telegram) и момент (до первой буквы/среди текста/после Enter).
Windows и драйвер здесь не проверены; результаты offline unit-тестов приложены.
